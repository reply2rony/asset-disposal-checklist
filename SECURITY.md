# Security Policy

This repository is a starter learning template with fictional sample data only.

- Do not commit real asset tags, serial numbers, real user data, or
  internal URLs. The template CSV contains made-up examples.
- Do not commit credentials or API keys. Keep those in your organisation's
  own secure store, never in a repo.
- If you find a security issue in the template itself, please open an issue
  describing it (without real company data).
